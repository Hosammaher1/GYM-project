# PulseFit Gym React Website

PulseFit Gym is a professional multi-page fitness website built with React, Vite, React Router DOM, and plain CSS. It is designed as a portfolio-ready front-end project that demonstrates reusable components, data-driven rendering, responsive layouts, and subtle modern UI interactions.

## Features

- Multi-page React Router navigation
- Sticky responsive navbar with active route styling
- Mobile hamburger menu using React state
- Premium dark fitness design with lime accent color
- Reusable program, trainer, pricing, stat, testimonial, and page hero components
- Data-driven rendering with arrays and `.map()`
- Responsive CSS Grid and Flexbox layouts
- Subtle hover effects, transforms, transitions, and entrance animation
- Contact form UI with browser validation
- Clean 404 page
- Accessible links, buttons, form labels, alt text, and focus styles

## Installation

```bash
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local URL printed by Vite, usually:

```text
http://localhost:5173/
```

## Build

```bash
npm run build
```
